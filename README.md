# tunehead

Tune digests and head fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/tunehead/

## Install / run

```bash
git clone https://github.com/theworker02/tunehead.git
cd tunehead
node src/cli.js
node --test
```
